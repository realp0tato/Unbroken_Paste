# UP 시험 모드 (개발용, #55)

앱 껍데기(#35)와 변환기 선택(#14)이 완성되기 전에, **변환 결과를 직접 붙여 보며 눈으로 비교**하기 위한 도구입니다. 켜 두면 복사할 때마다 변환 결과를 클립보드에 넣어 둡니다.

```bash
# 켜기 (저장소 루트에서). 처음 한 번은 변환기를 빌드하느라 수십 초 걸립니다
swift tools/ClipBridge.TryMode/try-mode.swift --target Hangul --mode Format

# 끄기: 터미널에서 Ctrl+C
```

| 옵션 | 값 |
|---|---|
| `--target` | `Hangul`, `Notion`, `Word` — 붙여넣는 순간 앱을 알아내지 않으므로 미리 정합니다 |
| `--mode` | `Format`(서식 적용), `Strip`(기호 제거) |

복사할 때마다 터미널에 한 줄이 나옵니다.

```text
[오후 6:47:34] C5 변환 (Markdown 글 → Hangul, Format) → 클립보드에 넣음
[오후 6:47:38] 통과 (인터넷 등 → 아직 변환기 없음)
```

## 비교하는 법

1. 시험 모드를 켜고 복사 → 대상 앱에 붙여넣기 (**UP 사용**)
2. Ctrl+C로 끄고 같은 내용을 다시 복사 → 붙여넣기 (**UP 없이**)

## 지금 연결된 변환기

앱(Helper)과 같은 실제 변환기 `UpClipConverter`(#14)를 씁니다. 출처 판별은 PRD 6.1, 대상별 변환기는 PRD 6.2 매트릭스를 따릅니다.

| 복사한 것 | Hangul | Notion | Word |
|---|---|---|---|
| Markdown 글 (일반 텍스트, 또는 Claude 앱 복사) | C5 | C6 | 통과 (C8 #12 전) |
| Excel | C1 | C2 | 통과 (Office 기본) |
| 인터넷 (AI 답변 드래그 복사 포함) | C3 | C4 | 통과 (C7 #10 전) |
| 일반 텍스트 | 통과 (TX #6 전) | 통과 | 통과 |

변환기가 Core에 추가되면 시험 모드도 자동으로 따라갑니다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `try-mode.swift` | 클립보드 감시, 복사한 앱 기록, 변환 결과를 클립보드에 기록 (macOS) |
| `Program.cs` | 형식 파일이 든 폴더를 받아 변환하고 결과 폴더를 씀 (Core 호출) |
