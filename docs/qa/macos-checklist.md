# macOS 빠른 체크리스트 (#39)

되는지 안 되는지만 확인한다. 되면 `[x]`, 안 되면 비워 두고 옆에 한 줄 메모. 자세한 기준과 3회 기록은 [검증 기록표](macos.md).

**준비:** 앱을 켜고, 메뉴 막대 슬라임 → Markdown 처리가 **서식 적용**인지 확인한다(8번만 기호 제거로 바꿈). 한글은 데스크톱 한글이 없으면 한컴독스 웹에 붙인다.

**"아직"** 표시는 아직 만들지 않은 기능이다. UP 없을 때처럼 원래대로 붙으면 정상.

---

## 1. 표 — Excel에서 복사

Excel에 머리글(굵게·가운데) + 2~3줄 표를 만들어 복사. 칸 안 줄바꿈, `1,234.50`, 병합 칸을 하나씩 넣는다.

- [ ] **한글:** 표로 붙고 칸 수·값이 같다. 굵게·정렬·테두리는 남고 Excel 글꼴·배경색은 없다
- [ ] **Notion:** Notion 표로 붙고 칸 수·값이 같다
- [ ] **Word:** UP 없을 때와 똑같이 붙는다
- [ ] **한 열만 복사 → 한글·Notion:** 표가 아니라 칸마다 한 줄(문단)로, 따옴표·빈 줄 없이

## 2. 표 — 웹에서 복사

위키백과 [대한민국의 행정 구역](https://ko.wikipedia.org/wiki/대한민국의_행정_구역)의 표 하나를 Chrome·Safari에서 복사.

- [ ] **한글:** 표로 붙고 사이트 글꼴·색·배경이 없다
- [ ] **Notion:** Notion 표로 붙는다
- [ ] **Word:** (아직) 원래대로 붙는다

## 3. 글 — 웹 기사·블로그

위키백과 [클립보드](https://ko.wikipedia.org/wiki/클립보드) 본문 몇 문단(소제목 포함), MDN [Clipboard API](https://developer.mozilla.org/ko/docs/Web/API/Clipboard_API)의 목록·코드 부분을 복사.

- [ ] **한글:** 사이트 글꼴·색·배경이 빠지고 제목·굵게·목록은 남는다
- [ ] **Notion:** 위와 같고 링크가 눌린다
- [ ] **Word:** (아직) 원래대로 붙는다
- [ ] **글 + 표 함께 복사 (행정 구역 문서의 표 위 문단부터 표 끝까지):** 글과 표가 모두 정리돼 붙는다

## 4. 글 — 일반 텍스트

텍스트 편집기(메모)에 빈 줄을 2~3줄씩 섞은 글을 써서 복사.

- [ ] **한글:** 빈 줄이 겹치지 않고 글자는 같다
- [ ] **Notion:** 위와 같다
- [ ] **Word:** 위와 같다

## 5. Markdown 적용된 버전 — AI 답변 복사 버튼

Claude 데스크톱 앱과 claude.ai(Chrome)에서 제목·굵게·목록·표가 있는 답변을 **복사 버튼**으로 복사. (질문 예: "회의록 양식을 제목, 굵은 글씨, 목록, 표를 넣어서 만들어 줘")

- [ ] **한글:** `#`·`**` 기호 없이 제목은 큰 굵은 글자(파란 제목 스타일 아님), 목록·표 적용
- [ ] **Notion:** 제목 블록·굵게·목록·표로 붙는다
- [ ] **Word:** (아직) 원래대로 붙는다
- [ ] **claude.ai(Chrome)에서 복사해도** 앱에서 복사한 것과 같게 붙는다

## 6. Markdown 적용된 버전 — 화면에서 드래그해 복사

이미 서식이 보이는 화면을 마우스로 드래그해 복사. GitHub의 README 화면(예: 이 저장소 첫 화면), Claude 답변 본문을 드래그.

- [ ] **한글:** 제목·굵게·목록이 남고 사이트 글꼴·색은 빠진다
- [ ] **Notion:** 위와 같고 제목이 제목 블록으로
- [ ] **Word:** (아직) 원래대로 붙는다

## 7. Markdown 원문 — 기호가 그대로 보이는 글

`#`·`**`·`-`·표(`| a | b |`)가 기호 그대로 있는 글을 복사. VS Code·텍스트 편집기로 연 `.md` 파일(예: 이 저장소 `README.md`), 또는 GitHub에서 **Raw** 버튼으로 연 원문 화면.

- [ ] **한글:** 기호가 사라지고 제목·굵게·목록·표로 바뀌어 붙는다
- [ ] **Notion:** 제목 블록·굵게·목록·표로 바뀌어 붙는다
- [ ] **Word:** (아직) 원래대로 붙는다
- [ ] **`file_name`, `2*3` 같은 일반 기호**는 지워지지 않는다

## 8. 기호 제거 옵션

메뉴 → Markdown 처리 → **기호 제거**로 바꾸고, **다시 복사하지 말고** 5·6·7의 자료를 붙인다.

- [ ] **5번 AI 답변 → 한글·Notion:** 제목·굵게 없이 그냥 글로, 기호도 없다
- [ ] **6번 드래그 복사 → 한글·Notion:** 그냥 글로 붙는다
- [ ] **7번 원문 → 한글·Notion:** 기호만 빠진 그냥 글로 붙는다
- [ ] **3번 웹 글 → 한글·Notion:** 그냥 글로 붙는다
- [ ] UP을 껐다 켜도 **기호 제거**가 그대로 선택돼 있다 (확인 후 **서식 적용**으로 되돌리기)

## 9. 망가지지 않나

- [ ] 1번 표를 **한 번** 복사해 한글 → Notion → 메모에 붙이면 각자 맞게, 메모에는 원래 내용
- [ ] A를 복사하고 바로 B를 복사해 붙이면 B가 붙는다
- [ ] 한글에 붙인 뒤 UP을 끄고 메모에 붙이면 원래 내용이 붙는다
- [ ] 이미지·Finder 파일 복사는 평소처럼 붙는다
- [ ] 손쉬운 사용 권한을 끄면 평소처럼 붙고, 다시 켜면 바뀌어 붙는다
- [ ] Notion 웹·한컴독스 웹(브라우저)에서도 바뀌어 붙는다

## 10. 화면 표시

- [ ] 복사하면 포인터 옆에 슬라임 동그라미가 떴다 사라진다
- [ ] 한글·Notion·Word에 붙이면 그 앱 아이콘이 떴다 사라진다
- [ ] 아이콘이 떠 있어도 타자·클릭이 평소처럼 된다
- [ ] 밝은·어두운 모드 모두 메뉴 막대 슬라임이 보인다
- [ ] 클립보드 메뉴에 최근 복사가 쌓이고, 누르면 다시 복사, 지우기가 된다
- [ ] 비밀번호 관리자·키체인에서 복사한 비밀번호는 기록에 안 쌓인다
