# macOS 빠른 체크리스트 (#39)

되는지 안 되는지만 확인한다. 되면 `[x]`, 안 되면 비워 두고 옆에 한 줄 메모. 자세한 기준과 3회 기록은 [검증 기록표](macos.md).

준비: 앱 켜기 → 메뉴 막대에 슬라임이 보이고 Markdown 처리가 **서식 적용**인지 확인.

## 1. 붙여넣으면 바뀌나

- [ ] Excel 표 → **한글**: 표로 붙고 Excel 글꼴·배경색이 없다
- [ ] Excel 표 → **Notion**: Notion 표로 붙는다
- [ ] Excel 표 → **Word**: UP 없을 때와 똑같이 붙는다
- [ ] 웹 글(위키백과) → **한글**: 사이트 글꼴·색이 빠지고 제목·굵게는 남는다
- [ ] 웹 글 → **Notion**: 위와 같고 링크가 눌린다
- [ ] 웹 표 → **한글·Notion**: 표로 붙는다
- [ ] Claude 답변(복사 버튼) → **한글**: `#`·`**` 기호 없이 큰 굵은 제목·목록·표로 붙는다
- [ ] Claude 답변 → **Notion**: 제목 블록·굵게·목록·표로 붙는다
- [ ] 빈 줄 많은 글 → **한글·Notion·Word**: 빈 줄이 겹치지 않는다

(웹 → Word, Claude 답변 → Word는 아직 기능이 없어 건너뜀)

## 2. 메뉴가 되나

- [ ] Markdown 처리를 **기호 제거**로 바꾸면, 다시 복사하지 않아도 Claude 답변이 그냥 글로 붙는다
- [ ] UP을 껐다 켜도 고른 옵션이 그대로다
- [ ] 슬라임 메뉴 → 클립보드에 최근 복사가 쌓이고, 누르면 다시 복사된다
- [ ] 비밀번호 관리자·키체인에서 복사한 비밀번호는 기록에 안 쌓인다
- [ ] UP을 다시 켜면 클립보드 기록이 비어 있다

## 3. 아이콘이 뜨나

- [ ] 복사하면 포인터 옆에 슬라임 동그라미가 떴다 사라진다
- [ ] 한글·Notion·Word에 붙이면 그 앱 아이콘이 떴다 사라진다
- [ ] 아이콘이 떠 있어도 타자·클릭이 평소처럼 된다
- [ ] 밝은 모드·어두운 모드 모두 메뉴 막대 슬라임이 보인다

## 4. 망가지지 않나

- [ ] 한 번 복사해서 한글 → Notion → 메모장에 붙이면 각자 맞게 붙고, 메모장엔 원래 내용
- [ ] A를 복사하고 바로 B를 복사해 붙이면 B가 붙는다
- [ ] 한글에 붙인 뒤 UP을 끄고 메모장에 붙이면 원래 내용이 붙는다
- [ ] 이미지·파일 복사는 평소처럼 붙는다
- [ ] 손쉬운 사용 권한을 끄면 평소처럼 붙고, 다시 켜면 변환된다
- [ ] Notion 웹·한컴독스 웹(브라우저)에서도 바뀌어 붙는다
