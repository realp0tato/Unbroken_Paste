# macOS 검증 기록표 (#39)

**하는 일:** 정해진 자료를 복사해서 한글·Notion·Word에 붙이고, 잘 붙었는지 보고 칸에 적는다. 칸마다 3번 해서 `✅✅✅`처럼 적는다.

| 표시 | 뜻 |
|---|---|
| ✅ | 기대 결과대로 붙음 |
| ❌ | 안 바뀌었거나 이상하게 붙음 → 스크린샷 저장 (`docs/qa/macos/<칸 이름>-<회차>.png`, 예: `A1-한글-2.png`) |
| ⏳ | 아직 만들지 않은 기능. 건너뜀 |

## 준비 (한 번만)

1. 앱 켜기: `cd macos/UnbrokenPaste && ./scripts/build-app.sh && open "build/Unbroken Paste.app"`
2. 로그 켜기 (터미널 하나 더): `log stream --level info --predicate 'subsystem == "app.unbrokenpaste.menubar"'`
   - 붙일 때마다 `paste write converter=C1 target=Hangul 3ms` 같은 줄이 나온다
   - `target=` UP이 알아본 붙일 곳, `converter=` 쓴 변환기. 각 묶음의 "로그" 값과 같으면 맞음
3. 메뉴 막대 슬라임 → Markdown 처리가 **서식 적용**인지 확인 (A~D는 서식 적용으로 한다)
4. 한글은 데스크톱 한글이 없으면 **한컴독스 웹**(브라우저)에 붙인다

| 검증한 사람 | 날짜 | macOS | 한글 (종류·버전) | Word | Notion (앱/웹) |
|---|---|---|---|---|---|
| | | | | | |

## A. 표 자료 — Excel에서 복사

**자료** (Excel에 직접 만든다)

| 이름 | 만드는 법 |
|---|---|
| A1 기본 표 | 머리글 `이름 · 부서 · 금액`(굵게, 가운데 정렬) + 2줄. 부서 칸 하나는 칸 안 줄바꿈(`개발` ↵ `2팀`, Option+Enter), 금액은 `1,234.50` 쉼표 서식 |
| A2 수식 표 | `품목 · 단가 · 수량 · 금액` + 2줄 + 합계 줄. 금액은 `=B2*C2`, 합계는 `=SUM(...)`, 칸 하나는 백분율 `12.5%`, 하나는 날짜 `2026-10-30` |
| A3 병합 표 | 첫 줄 A1:B1을 가로 병합(`상반기 실적`), C1:C2를 세로 병합(`비고`) + 값 2줄 |
| A4 한 열 | A열에만 4칸: `첫 줄` / 빈칸 / 칸 안 줄바꿈 / `"따옴표"` 든 글 |

**기대 결과**

| 붙일 곳 | 이러면 ✅ | 로그 |
|---|---|---|
| 한글 | 칸 수·값이 같고 굵게·정렬·테두리 유지. Excel 글꼴·배경색은 없음. 수식은 계산된 값으로. A4는 칸마다 한 문단, 따옴표·빈 문단 없음 | C1 |
| Notion | Notion 표로 붙고 칸 수·값이 같음. 병합 칸은 첫 칸에 값을 두고 풀림. A4는 칸마다 한 줄 | C2 |
| Word | UP을 껐을 때와 똑같이 붙음 (Word는 원래 잘 붙어서 그대로 둔다) | PASS |

**기록**

## D. 일반 글 — 메모·텍스트 편집기에서 복사

**자료:** 텍스트 편집기(또는 메모)에 아래처럼 빈 줄을 2~3줄씩 섞어 써서 복사한다.

```text
첫 번째 문단입니다.


두 번째 문단입니다.
바로 아랫줄입니다.



세 번째 문단입니다.
```

**기대 결과:** 세 곳 모두 빈 줄이 겹쳐 생기지 않고 문단 사이 간격이 한 번만 있음. 글자는 원문과 같음. 로그 `TX`

## E. 메뉴 옵션 — "기호 제거"로 바꿔서

메뉴 막대 슬라임 → Markdown 처리 → **기호 제거**로 바꾼다. **다시 복사하지 말고** 바로 붙여 본다(옵션은 붙일 때 바로 적용).

**기대 결과:** 제목·굵게·목록 모양 없이 **그냥 글**로 붙음. 글자는 원문과 같고 `#`·`**` 같은 기호도 없음. Notion이 제목·굵게로 바꾸지 않음.

| 자료 | 한글 | Notion | 메모 |
|---|---|---|---|
| C1 앱 답변 | | | |
| B1 기사형 글 | | | |

| 확인 | 결과 | 메모 |
|---|---|---|
| UP을 껐다 켜도 "기호 제거"가 그대로 선택돼 있음 | | |

끝나면 다시 **서식 적용**으로 돌려 둔다.

| 번호 | 해 볼 것 | 이러면 ✅ | 결과 (3회) | 메모 |
|---|---|---|---|---|
| F1 | A1을 **한 번** 복사해서 한글 → Notion → 텍스트 편집기 순서로 붙이기 | 한글은 한글용 표, Notion은 Notion 표, 텍스트 편집기는 원래 내용 | | |

## 정리

**앱별로 안 되는 것** (안 되는 서식은 발표에서 된다고 하지 않는다)

| 앱 | 잘 되는 것 | 안 되거나 다르게 붙는 것 |
|---|---|---|
| 한글 | | |
| Notion | | |
| Word | | |

**바로 이슈로 만들 문제** — 한 번이라도 나오면 스크린샷과 함께 이슈를 만든다.

- 복사한 내용이 사라지거나 일부가 빠짐
- 같은 내용이 두 번 붙음
- 엉뚱한 창으로 커서가 넘어감
- 다른 앱용으로 바꾼 결과가 붙음 (예: Notion에 한글용 결과)
