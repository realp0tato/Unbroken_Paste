# macOS 검증표 (#39)

**하는 일:** 복사해서 붙여 보고, 잘 붙었는지 눈으로 보고, ✅ 또는 ❌를 적는다. 항목마다 3번씩.

- ✅ UP을 껐을 때보다 깔끔하게 붙음 (Word는 UP을 껐을 때와 같으면 ✅)
- ❌ 안 바뀌었거나 더 이상하게 붙음 → 스크린샷을 `docs/qa/macos/<번호>-<회차>.png`로 저장
- ⏳ 아직 만들지 않은 기능이라 건너뜀

## 시작 전에 (한 번만)

1. 앱 켜기
   ```bash
   cd macos/UnbrokenPaste && ./scripts/build-app.sh && open "build/Unbroken Paste.app"
   ```
2. 터미널을 하나 더 열고 아래를 켜 둔다. 붙여넣을 때마다 한 줄씩 나온다.
   ```bash
   log stream --level info --predicate 'subsystem == "app.unbrokenpaste.menubar"'
   ```
   이런 줄이 나오면 UP이 일한 것이다.
   ```text
   paste write converter=C2 target=Notion 3ms
   ```
   - `target=` 어디에 붙였는지 UP이 알아본 앱 (Hangul·Notion·Word·Other)
   - `converter=` 쓴 변환기. 아래 표의 "로그" 칸과 같으면 맞게 동작한 것
3. 메뉴 막대 슬라임 → Markdown 처리가 **서식 적용**인지 확인
4. 아래 칸 채우기

## 1. Excel 표

Excel에 표를 만든다. 머리글은 굵게·가운데 정렬, 숫자 `1,234.50`, 칸 하나는 줄바꿈 넣기. 그 표를 Excel에서 복사해 붙인다.

| 번호 | 붙일 곳 | 잘 붙었다는 기준 | 로그 | 1 | 2 | 3 | 메모 |
|---|---|---|---|---|---|---|---|
| 1-1 | 한글 | 칸 수·값이 같고 굵게·정렬·테두리 유지, Excel 글꼴·배경색 없음 | C1 | | | | |
| 1-2 | Notion | Notion 표로 붙고 칸 수·값이 같음 | C2 | | | | |
| 1-3 | Word | UP을 껐을 때와 똑같음 | PASS | | | | |
| 1-4 | 한글 (한 열만 복사) | 칸마다 한 문단, 따옴표·빈 줄 없음 | C1 | | | | |
| 1-5 | Notion (한 열만 복사) | 칸마다 한 줄, 따옴표·빈 줄 없음 | C2 | | | | |

## 3. Claude 답변 (Markdown)

Claude 답변 아래의 **복사 버튼**으로 복사한다. 제목(`#`), 굵게(`**`), 목록, 표가 있는 답변이 좋다.

**메뉴가 "서식 적용"일 때**

| 번호 | 붙일 곳 | 잘 붙었다는 기준 | 로그 | 1 | 2 | 3 | 메모 |
|---|---|---|---|---|---|---|---|
| 3-1 | 한글 | `#`·`**` 같은 기호가 안 보이고, 제목은 큰 굵은 글자(파란 제목 스타일 아님), 목록·표 적용 | C5 | | | | |
| 3-2 | Notion | 제목이 Notion 제목 블록, 굵게·목록·표 적용 | C6 | | | | |
| 3-3 | Word | 3-1과 같음 | C8 | ⏳ | ⏳ | ⏳ | 아직 없음 (#12) |

**메뉴를 "기호 제거"로 바꾼 뒤** (다시 복사하지 말고 바로 붙여 본다)

| 번호 | 붙일 곳 | 잘 붙었다는 기준 | 로그 | 1 | 2 | 3 | 메모 |
|---|---|---|---|---|---|---|---|
| 3-4 | 한글 | 기호만 빠지고 글자는 원문과 같은 그냥 글 | C5 | | | | |
| 3-5 | Notion | 위와 같음, Notion이 제목·굵게로 바꾸지 않음 | C6 | | | | |
| 3-6 | — | UP을 껐다 켜도 "기호 제거"가 그대로 선택돼 있음 | — | | | | |

끝나면 메뉴를 다시 **서식 적용**으로 돌려 둔다.

## 바로 이슈로 만들 문제

- 복사한 내용이 사라지거나 일부가 빠짐
