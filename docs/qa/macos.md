# macOS 검증 기록 (#39)

PRD [9.1](../../prd.md#91-기능-성공-기준)의 macOS 시험과 [11. MVP 완료 조건](../../prd.md#11-mvp-완료-조건)의 macOS 항목을 Mac에서 확인한 기록이다. 항목마다 3회 반복한다.

## 준비

```bash
cd macos/UnbrokenPaste
./scripts/build-app.sh && open "build/Unbroken Paste.app"
```

로그는 터미널을 하나 더 열어 켜 둔다. 붙여넣을 때마다 `paste target=… app=…`(대상 인식)과 `paste write converter=… target=…`(쓴 결과)가 찍힌다.

```bash
log stream --level info --predicate 'subsystem == "app.unbrokenpaste.menubar"'
```

입력은 매번 같게 맞추려고 저장한 샘플을 쓴다([샘플 설명](../../tests/fixtures/README.md)). 샘플마다 넣는 방법이 다르다.

| 샘플 | 넣는 방법 | 이유 |
|---|---|---|
| Chrome 웹 4개(`web/mac-chrome-*`), Claude 답변(`markdown/mac-claude-answer`) | 복원 도구로 되돌려 넣기 | 샘플 안의 페이지 주소로 출처를 판별해서, 터미널에서 넣어도 결과가 같다 |
| Excel 4개(`excel/mac-*`) | `bash tests/fixtures/tools/collect-excel-samples.sh`로 Excel에 같은 표를 만들고 **Excel에서 직접 복사** | UP은 복사할 때 앞에 있던 앱으로 Excel을 판별한다. 터미널에서 되돌려 넣으면 터미널에서 복사한 것으로 보여 통과(PASS)가 된다 |
| Safari 웹 4개(`web/mac-safari-*`) | `meta.json` 설명의 페이지를 Safari로 열어 **같은 구간을 직접 복사** | Safari는 페이지 주소를 넣지 않아서 앞에 있던 앱(Safari)으로 판별한다. 이유는 Excel과 같다 |

복원 도구는 저장소 맨 위 폴더에서 실행하고, 실행한 뒤 대상 앱으로 가서 붙여넣는다(되돌려 넣는 것도 새 복사로 감지된다).

```bash
swift tests/fixtures/tools/restore-mac-clipboard.swift tests/fixtures/web/mac-chrome-article
```

로그의 `results … source=` 값으로 출처가 맞게 판별됐는지 먼저 확인한다(Excel·Web·Markdown·PlainText).

## 2. Markdown·AI 답변

샘플은 `markdown/mac-claude-answer`(Claude 답변, HTML도 함께 있음). 메뉴의 Markdown 처리를 바꿔 가며 같은 샘플을 붙인다.

| # | 시험 | 대상 | 모드 | 기대 변환기 | 통과 기준 (PRD 9.1) | 1회 | 2회 | 3회 | 비고 |
|---|---|---|---|---|---|---|---|---|---|
| 2-1 | AI 답변 → 한글 | 한글 | 서식 적용 (기본) | C5 | `#` 20pt·`##` 16pt·`###` 13pt 굵은 글자, 제목 스타일 없음. `**`→굵게, 목록·표 적용, 기호가 보이지 않음 | | | | |
| 2-2 | AI 답변 → Notion | Notion | 서식 적용 | C6 | `#`→제목 1, `##`→제목 2 블록. 굵게·목록·표 적용, 기호 안 보임 | | | | |
| 2-3 | AI 답변 → Word | Word | 서식 적용 | C8 | 2-1과 같은 기준 | ⏳ | ⏳ | ⏳ | C8 미구현 (#12) |
| 2-4 | AI 답변 → 한글 | 한글 | 기호 제거 | C5 | `#`·`**`·`-`·`>`·링크 기호가 모두 빠지고 글자·번호·코드 내용은 원문과 같음. `file_name`, `2*3`은 유지 | | | | |
| 2-5 | AI 답변 → Notion | Notion | 기호 제거 | C6 | 위와 같음 + Notion이 제목·굵게로 자동 변환하지 않음 | | | | |
| 2-6 | AI 답변 → Word | Word | 기호 제거 | C8 | 2-4와 같음 | ⏳ | ⏳ | ⏳ | C8 미구현 (#12) |

## 4. 붙여넣기 흐름·안전성

| # | 시험 | 방법 | 통과 기준 (PRD 9.1, 11) | 1회 | 2회 | 3회 | 비고 |
|---|---|---|---|---|---|---|---|
| 4-1 | 한 번 복사 → 여러 앱 | Excel에서 기본 표(`mac-basic-table`)를 한 번 복사하고 한글 → Notion → 텍스트 편집기 순서로 붙임 | 각각 C1 / C2 / 원본이 붙고 이전 대상 결과가 섞이지 않음 | | | | |

| 4-4 | 옵션 전환 | AI 답변을 한 번 복사하고 Notion에 붙인 뒤, 메뉴에서 기호 제거로 바꿔 다시 붙임 | 다시 복사하지 않아도 결과가 바뀜 | | | | |
| 4-5 | 옵션 유지 | 4-4 뒤 UP 종료 → 다시 실행 | 기호 제거가 그대로 선택됨 | | | | |
| 4-6 | Helper 없음 | `pkill -f UnbrokenPaste.Helper`를 반복해 Helper가 없는 동안 붙임 | 원본이 그대로 붙음 (원본 손실·누락·중복 없음), 메뉴에 변환 엔진 상태 표시 | | | | |
| 4-7 | 미지원 입력 | 이미지·파일(Finder에서 파일 복사)을 한글·Notion에 붙임 | 원래대로 붙음 | | | | |
| 4-8 | UP 종료 후 원본 | 한글에 붙여 결과를 쓴 상태에서 UP 종료 → 텍스트 편집기에 붙임 | 변환 결과가 아니라 원본이 붙음 | | | | |

| 4-10 | 입력 경로 Cmd+V | 1~3의 모든 시험 | Cmd+V에서 변환됨 | | | | |
| 4-11 | 입력 경로 메뉴 붙여넣기 | 대상 앱의 편집 → 붙여넣기, 오른쪽 클릭 → 붙여넣기 | 원본이 붙고 오류 없음 (메뉴 경로 변환은 P1, #26) | | | | |
| 4-12 | 웹 대상 인식 | Notion 웹(제목에 Notion이 없는 페이지 포함)·한컴독스 웹에 붙임 | 로그 `paste target=Notion` / `target=Hangul`, `browser url=<도메인>` | | | | |
